## 🚀 Quick Start

### 1. Extract
```bash
tar -xzf habit-tracker-complete.tar.gz
cd v0-project
```

### 2. Install
```bash
npm install
```

### 3. Configure Supabase
Create `.env.local`:
```env
NEXT_PUBLIC_SUPABASE_URL=your_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_key
```

### 4. Run
```bash
npm run dev
```

Visit `http://localhost:3000`
